# Imagify

A minimal yet powerful React development template optimized for speed and scalability, built with Vite, Tailwind CSS, and ESLint integration. It streamlines the development process, enabling rapid iteration and high-quality code.

## 📖 Overview

Imagify is a minimal yet powerful React development template optimized for speed and scalability, built with Vite, Tailwind CSS, and ESLint integration. It streamlines the development process, enabling rapid iteration and high-quality code.

## ✨ Why Imagify?

This project aims to simplify the creation of scalable React applications with an efficient build environment. The core features include:

- 🔥 **Hot Module Replacement**: Instantly see code changes without full reloads, boosting development speed
- 🎯 **ESLint Integration**: Enforces coding standards and best practices for consistent, maintainable code
- 🌐 **Modern Tooling**: Combines Vite, React, and Tailwind CSS for a fast, responsive, and styled UI
- 🔧 **Modular Architecture**: Reusable components and clear project structure facilitate scalable development
- 🚀 **Fast Build & Refresh**: Optimized workflows for quick builds and seamless updates

## 🛠️ Tech Stack

- **React** - A JavaScript library for building user interfaces
- **Vite** - Next generation frontend tooling with lightning-fast HMR
- **Tailwind CSS** - Utility-first CSS framework for rapid UI development
- **ESLint** - Code quality and consistency enforcement
- **JavaScript** - Primary programming language

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (version 14 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

## 🔧 Installation

1. Clone the repository:
```bash
git clone https://github.com/vermayatharth/Imagify.git
```

2. Navigate to the project directory:
```bash
cd Imagify
```

3. Install dependencies:
```bash
npm install
```

## 🚀 Running the Application

### Development Mode

To start the development server with hot module replacement (HMR):

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or another port if 5173 is in use).

### Production Build

To build the application for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
